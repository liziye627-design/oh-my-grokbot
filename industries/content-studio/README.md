# 第二层内容 Bot 核心

`oh-my-content-studio@0.2.0` 将内容专业方法和可执行工具组合成六个岗位。宝玉的采集、排版与草稿工具已随包交付；卡兹克写作方法已适配为真实作者的长文 Skill。

`produce-piece`：简报 → 来源/文风 → 大纲 → 正文 → 标题与 X 改写 → HTML 排版 → 独立审稿 → 发布前交接。`next-topics` 使用用户导出数据复盘。

可安装不等于原生账号已执行。正文由宿主模型完成，宝玉脚本需要在实际运行环境安装 Bun 锁定依赖。微信提交保持独立授权，不因准备草稿而自动发布。

[安装、依赖与层级说明](../../docs/content-production.md) · [真实文章验证](../../examples/content-studio/real-article/README.md)
